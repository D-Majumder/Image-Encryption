# Image-Encryption

A simple image encryption and decryption demonstration using Python.

## Overview

A simple image encryption and decryption showcase using Python and AES (via `pycryptodome`).

## Features

- Encrypt and decrypt any image file.

## Setup

```bash
git clone https://github.com/D-Majumder/Image-Encryption.git
cd Image-Encryption
pip install pycryptodome
python Image_Encrypt.py
```
